# Мир танков на macOS

Данная сборка позволяет играть в Мир танков без виртуальной Windows на macOS в 1 клик с Apple silicon с работаюбщим Леста Гейм Центром и МОСТом (менеджер модов).

Видео с геймплеем:

#### [YouTube](https://www.youtube.com/watch?v=7CJCI_9IcEo)

#### [Rutube](https://rutube.ru/video/de6cbdcc3d2ae8d2a3a0896d3e77643e)


## Установка

Проект перешёл на донатно-подписочную основу. Готовую сборку можно получить на проекте Playmac:

https://playmac.ru/game/mir-tankov
